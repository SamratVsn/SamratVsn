I enjoy turning ideas into functional applications, understanding the engineering decisions behind them, and continuously improving the way I build software.

My primary interests include:

- 📱 Native Android development with Kotlin and Jetpack Compose.
- 🏗️ Modern Android architecture and maintainable application design.
- 🌐 Open-source software and developer communities.
- 🇳🇵 Building technology inspired by problems and opportunities in Nepal.
- 📚 Continuous learning through projects, documentation, and experimentation.

I believe good software isn't just about making something work. It's about understanding why it works and building it well.

## Featured Projects

Projects I've built and actively worked on.

### 🏛️ [Avalokan — Nepal Heritage Explorer](https://github.com/SamratVsn/Avalokan)

My flagship project.

A native Android application exploring Nepal's historical, cultural, religious, and natural heritage, alongside local events and experiences.

Designed to make discovering Nepal's heritage more accessible through location-aware discovery and an offline-first approach.

**Tech Stack**

`Kotlin` `Jetpack Compose` `Material 3` `Hilt` `Room` `Firebase` `StateFlow`

**Focus:** Offline-first architecture · Heritage discovery · User experience

---

### 📝 [Tasks](https://github.com/SamratVsn/ToDo)

A productivity application designed around task management, organization, and focused work sessions.

Built as a way to explore modern Android development, application architecture, and practical productivity features.

**Tech Stack**

`Kotlin` `Jetpack Compose` `Material 3` `Room` `DataStore`

**Focus:** Productivity · Local persistence · Android architecture

---

### 🎬 [The Movie](https://github.com/SamratVsn/TheMovie)

Explore movies, discover content, and experiment with integrating external APIs and authentication into Android applications.

**Tech Stack**

**Focus:** API integration · Authentication · Data management
